# chasebot performance reports

Auto-published mirror of the `reports/` directory from the chasebot trading
server, refreshed every sync cycle (2026-08-22 19:28 UTC).

These files are the machine's own self-assessment: account balance, per-strategy
verdicts, recent trades, tuner diary and deploy history. Reports only — no source
code, no configuration, no credentials. Rewritten as a single commit each cycle,
so there is no history here to browse.
